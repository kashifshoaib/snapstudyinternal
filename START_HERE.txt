1. Open PowerShell (as Administrator)

2. Run these commands:

   cd D:\repo\hackathon\study
   .\deploy-complete.ps1

3. Follow the prompts:

   ✓ Enable Bedrock access (if prompted)
   ✓ Wait 10-12 minutes for deployment
   ✓ Done! (Both Backend + Frontend deployed)

🆘 NEED HELP?

Common Issues:
→ "AWS credentials not found" - Run: aws configure
→ "Bedrock access denied" - Enable in AWS Console (us-east-1)
→ "Python not found" - Install from python.org
→ "Deployment failed" - Check CloudFormation in AWS Console

Full troubleshooting: See QUICK_DEPLOY.md
