🧠 SnapStudy — Your AI Tutor That Learns How You Learn
💡 Inspiration
We’ve all been there — staring at a 2-hour tutorial at midnight, wishing someone could just explain it clearly in 10 minutes.
 That frustration is multiplied for millions of learners with ADHD or short attention spans, who struggle to focus through long, linear lessons.
Traditional e-learning assumes sustained concentration — but in reality, 96% of online courses are abandoned, and the average attention span has dropped below 8 seconds.
SnapStudy was born to fix this — by reimagining how learning works. Instead of forcing learners to adapt to the content, SnapStudy adapts the content to their brain. It’s an autonomous AI tutor that transforms long tutorials into personalized, bite-sized lessons — built for neurodiverse learners who learn best in short, engaging bursts.

🚀 What it does
SnapStudy converts long tutorials, PDFs, or documents into adaptive micro-learning experiences powered by AWS Bedrock and Claude 3.5 Sonnet.
Learners can:
📘 Upload any material and receive AI-generated micro-lessons


💬 Chat with their AI Study Buddy for explanations or clarification


🧠 Reinforce concepts through auto-generated quizzes and recaps


📊 Track learning progress with adaptive difficulty and spaced reinforcement


SnapStudy doesn’t just summarize — it teaches, adjusting pace, style, and focus based on how each learner engages.

🏗️ How we built it
SnapStudy is powered entirely by AWS-managed, serverless architecture, optimized for scalability, autonomy, and security.
🧩 Core AWS Architecture
Foundation Model: Amazon Bedrock with Claude 3.5 Sonnet


Autonomous Agents: Bedrock Agents (Learning Agent + Adaptive Agent) with AgentCore primitives


Agent Orchestration: Python async workflows integrated with Bedrock Agent Runtime


Knowledge Base: Bedrock Knowledge Base with OpenSearch Serverless for RAG


Data & Storage: DynamoDB (6 tables), S3 (content + frontend)


APIs & Access Control: API Gateway + IAM + Cognito User Pool


Monitoring & Reliability: CloudWatch Dashboard, Alarms, WAF, Bedrock Guardrails


Infrastructure as Code: AWS CDK (Python) for repeatable deployments


💻 Application Layer
Frontend: React + Vite + TypeScript (modern, responsive, accessible interface)


Backend: FastAPI with async orchestration and JWT authentication


AI Agents: Bedrock Learning Agent (content generation) + Adaptive Agent (path optimization)


AI Pipeline: Content Analysis → Agent Reasoning → Micro-lesson Generation → Adaptive Quizzing → Performance Analysis → Autonomous Adaptation


Agent Functions: 6 autonomous action functions (analyze_performance, adapt_path, generate_content, update_progress, get_context, recommend_action)


This architecture enables TRUE autonomous AI decision-making using Bedrock AgentCore primitives, not just prompt engineering.

## 🚀 Technical Highlights for Judges

### Why This Solution Demonstrates TRUE Autonomous AI

1. **Bedrock Agents (Not Prompts):** Uses actual AWS Bedrock Agent service with AgentCore primitives for reasoning, memory, planning, and function invocation

2. **Multi-Agent Architecture:** Two specialized agents (Learning + Adaptive) with distinct capabilities working autonomously

3. **Knowledge Base Integration:** Bedrock Knowledge Base with OpenSearch Serverless for RAG-powered content retrieval

4. **Agent Action Functions:** 6 Lambda functions that agents autonomously invoke based on their reasoning:
   - analyze_student_performance
   - adapt_learning_path
   - generate_personalized_content
   - update_learning_progress
   - get_student_context
   - recommend_next_action

5. **Autonomous Decision Pipeline:** Agents analyze performance → reason over context → make decisions → invoke actions → adapt learning path — all without human intervention

6. **Production-Ready Infrastructure:** Full AWS CDK deployment with IAM roles, security policies, monitoring, and observability
